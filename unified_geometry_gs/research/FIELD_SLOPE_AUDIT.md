# 已有 field-occ 直通导数：平移不变性检查

2026-10-12。检查对象是本项目已有 `docs/FIELD_OCC_A.md` 与
`render_backward.cu` 的 slope-specific 分支，**没有修改生产内核**。
该文档已明确声明使用 straight-through estimator（STE）；以下发现属于
近似偏差的定量检查，不能描述为未声明的精确反传错误。

## 连续目标的全导数

固定贡献列表，令 H(t,θ)=−log T(t,θ)，中位根满足 H(t*,θ)=−log q。
若 H_t(t*,θ)>0，且下述二阶偏导存在（对本模型，充分条件是 t* 不等于任何
贡献基元的峰位），界面斜率 S(θ)=−T_t(t*,θ)=q H_t(t*,θ)，则

\[
\frac{dt^*}{d\theta}=-\frac{H_\theta}{H_t},\qquad
\frac{dS}{d\theta}
=q\left(H_{t\theta}-\frac{H_{tt}H_\theta}{H_t}\right).
\]

这里包含根移动引起的曲率项。固定根的局部导数 qH_tθ 不是全导数。
H_t=0 时公式不可用，参见 `MEDIAN_SOLVER_THEORY.md` 的临界反例。
即便 H_t>0，t*=pᵢ 处的 |t−pᵢ| 也可能使 S 不可微；中位根本身的
一阶可微性并不保证根处斜率的可微性。
这些是标准链式法则和隐函数条件的应用，不单独构成原创方法。

令 ρᵢ=1/σᵢ、δᵢ=(t*−pᵢ)ρᵢ、gᵢ=αᵢexp(−δᵢ²/2)，q=0.5 时

\[
S=\sum_i \frac14\frac{g_i}{1-g_i}|\delta_i|\rho_i.
\]

当前 STE 的透明度局部项保留了 ∂S/∂gᵢ；峰值和逆宽度项只保留显式
|δᵢ|ρᵢ 的导数，未纳入 gᵢ 随 δᵢ 的变化，也没有纳入 t*(θ) 移动。
因此它既不是连续 S 的全导数，也不是完整的固定根偏导。
生产前向采用最终小括区的割线斜率，故即便实现上述全导数，也仍与对
离散前向逐分支求导不同，需明确选择要优化的目标。

## 不依赖真实重建标签的必要条件

全部峰值同时平移 c，连续透射率满足 T_c(t)=T(t−c)。所以中位根移动 c，
根处的 S 完全不变：ΣᵢdS/dpᵢ=0。
这是一维参数空间内的必要不变性；不等同于真实 3D 场景平移，因为真实
相机投影和像素贡献列表也可能改变。

一个 α=0.9、p=2、σ=0.1 的基元具有常规有限中位根，远离临界 α=0.75。
连续目标对 p 的全导数为 0；现有 STE 转写给出约 +75。
α=0.6 的后峰根例给出约 −14.0625，混合基元例给出约 −3.14774。
这些值是斜率对归一化峰位的导数，不是训练损失梯度或质量指标。

`audit_field_slope.py` 在四个合成例上执行独立 torch float64 偏导、隐式全导数、
重新求根有限差分及共同平移检查。全导数与有限差分最大绝对误差为
5.0341×10⁻⁶；共同平移的全导数之和绝对值 ≤4.45×10⁻¹⁶。
原始参数、各项梯度及生产源文件 SHA256 见 `results/field_slope_calculus_v2.json`。
v2 仅补明二阶可微条件，数值结果与保留的 v1 一致。

## 实际含义与下一步

已有 field-occ 失败实验不能据此直接判为“只因梯度错了”。STE 可能有有益
归纳偏置，真实优化还受像素有效性、透明度裁剪、外观监督与密度控制影响。
当前 NCC 成对训练的 λ_field_occ=0，与本检查无关。

若以后重新研究该路线，应先在隔离后端比较现有 STE、完整固定根偏导、
包含根移动的全导数；用有限差分和上述平移不变性检查，再做单因素训练。
在此之前不重启历史 field-occ 扫参，也不声称已有几何改善。

复现（uggs 环境，仅 CPU）：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python research/audit_field_slope.py \
  --out research/results/new_field_slope_calculus.json
```
