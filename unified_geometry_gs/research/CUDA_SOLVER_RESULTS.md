# 冻结模型的 GPU 求根对照

2026-10-12；RTX 5090 Laptop GPU；三个旧模型 scan37/55/63；
每个模型使用事先 CPU 诊断中的同一 8 个相机，共 24 个视角。
每个视角先预热，各变体和 depth on/off 的执行顺序按 seed 0 随机化；
5 轮，每轮连续 20 次渲染，CUDA event 计时。
报告量是各视角轮次中位数，再对 8 个视角求均值。

## 当前结果

原始同源 JIT 五轮控制的平均 GPU 时间分别为 19.7583、13.6302、10.9773 ms。
四轮控制分别为 17.0327、11.7473、9.3860 ms。
视角内延迟比的中位数为 0.8621、0.8634、0.8551，
对应约 13.8%、13.7%、14.5% 的延迟降低。
这是冻结模型带深度渲染的结果，不是整体训练加速。

hybrid 原型分别为 24.8066、16.6917、13.7764 ms，
延迟比中位数为 1.2504、1.2234、1.2544，即慢约 22%～25%。
它保留原第一轮九点搜索，再尝试一次 Newton 修正和局部端点检查，
失败时执行历史剩余四轮。额外遍历、回退和寄存器压力可能解释代价，
但尚未用 profiler 隔离各项，不能把推测当测量结论。
这否定当前 GPU 实现的效率优势，不能推广为所有 Newton 实现必然更慢。
CPU 参考使用带权括区、多次 Newton 和高精度回退，和此 GPU 原型并非同一算法。

## 正确性范围

同源 JIT control 与已安装后端在 24 个完整图像上，深度、有效性、RGB、
alpha 和法向的最大差均为 0，计时也接近；这提供了编译控制。
所有变体的完整深度有效性掩码一致，RGB、alpha 和法向最大差为 0。
四轮与原五轮的全图最大深度差约 5.866×10⁻⁵（归一化相机深度单位）；
hybrid 最大差约 2.265×10⁻⁶。

每场景预定 1024 个像素的 CPU 对照中，三个变体均无有效性不一致，
在共同有效射线中误差均≤10⁻⁴。没有验证全部像素的真实根误差。
反向梯度与网格核验结果见下；没有验证训练轨迹或跨场景泛化。
hybrid 对接受像素输出解析 qH_t，原输出是有限括区 secant，斜率通道并不等价。

## 几何代价验证

`run_solver_mesh_pair.py` 在 `experiments/solver_mesh_v1` 为每个旧模型分别
用同源五轮和四轮后端重新提取网格，并用 evaluator seed 0 评估。
两组共享同一冻结 PLY，voxel=0.002、trunc=4、depth_max=8、cluster=1，
输出放在新模型目录，原模型元数据与历史网格保留。

在提取前设定的工程容差：每个场景 |Δoverall|≤0.0005 mm，
两项有向距离的增加分别≤0.0005 mm。它不是统计等价性检验。
六组提取/评估均完成，三个场景均在上述工程容差内：
Δoverall 分别为 scan37 −0.00001495、scan55 +0.00009067、scan63 −0.00009111 mm。
这些微小变化不作为精度改善声明。一个 evaluator seed 尚不提供统计等价性保证。
四轮细分是效率基线，不作为新颖性贡献。理论误差传播边界见 `DEPTH_ERROR_BUDGET.md`。

六个固定视角、预定抽样有效像素的真实 CUDA 深度反传均有限；但相对五轮
控制的参数梯度 L2 漂移最高约 1.396%，超过设定的 0.1% 工程门槛。
这只是梯度漂移对照，不是独立的导数正确性参考；没有训练收益保证。
同后端重复控制已完成：最大相对 L2 漂移为 2.354×10⁻⁶，
远小于四轮相对五轮的最高约 0.01396；24 个参数组中 19 个超过 0.001。
本次观察到的漂移不能由该重复控制中的 CUDA 累加波动解释。
