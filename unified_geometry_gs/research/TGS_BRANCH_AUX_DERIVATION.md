# TGS 分段导数、max 次梯度与辅助图的核验依据

以下结论针对固定可见性、排序和贡献分支。它们补充已有窗口/合成推导，不构成新颖性认证。

## 1. alpha 上限

令 a_raw=o*(-phi/r)^sigma，a=min(0.99,a_raw)。在 a_raw>0.99 的开邻域内，a 是常数，
所以它对窗口形状、sigma、opacity 的普通导数全为零。颜色仍通过权重 T*a 影响 RGB，
depth/normal 的直接路径也仍存在；不能把整个三角形的反传全部置零。
在 a_raw=0.99 处没有唯一普通导数，选择局部链式因子0或1均为相邻分支的广义导数选择。

新隔离实现只在从 dL/da 往 a_raw 的链上施加零因子。背景与遮挡递推、颜色梯度及
depth/normal 直接项在此之前已计算，不受这个局部选择影响。
原实现保留非零链式因子，其行为类似直通代理梯度；本核验不能据此推断作者是否有意为之。

## 2. max 平局不能无权重相加

phi=max_k phi_k。若有K条活跃边，合法的分支梯度选择可写为
sum_k w_k grad(phi_k)，w_k>=0、sum_k w_k=1（仅在活跃边上分配）。
选择第一条精确达到 max 的边，就是一个明确的相邻光滑分支选择。
直接给所有活跃边系数1，权重和变为K，通常不是同一个广义梯度。
这里不把 max 平局处的有限差分指定为某个唯一普通梯度。

有一个更强、无需指定唯一梯度的检验。对固定像素x，让所有屏幕顶点作
q_i(t)=x+exp(t)(q_i(0)-x)。所有 phi_k 和 r 都同比放大，u=-phi/r 恒定，故 a 恒定。
每个活跃分支的梯度沿该同心缩放方向均为零；它们的任何凸组合也必须为零。
若边距离项被累加K次，而半径项只传播一次，方向导数变成

```
dL/da * sigma * a * (K-1)
```

这证明了一个可证伪的不变性约束。测试三角形(32,32)、(192,32)、(32,152)，像素(60,60)，
两条轴向边距离相等且最大，r=40、u=0.7。真实缩放方向导数为0，旧累加预测约0.283809。
实际 native VJP 给0.283808524，选择一个精确max边后变为1.806e-8。
float32正负扰动未严格落在实数同心缩放路径上，FD零附近有舍入噪声，不能用其相对误差
定义“不可微点梯度精度”；完整记录仍保留。

## 3. 法线长度下限

相机空间叉积v=R*((p1-p0) cross (p2-p0))，前向 n=v/max(|v|,c)，c=1e-4。
在两个开分支上，Jacobian 分别为

```
|v| > c:  dn/dv = (I - n n^T)/|v|
|v| < c:  dn/dv = I/c
```

原反传使用上式第一种单位化形式，即使前向已经落入第二分支。
第二种分支必须保留叉积长度的变化，不能继续投影掉径向分量。
在 |v|=c 处，两侧 Jacobian 不同；新诊断版本明确选常分母一侧，不声称普通导数唯一。
朝向相机的符号在本测试邻域不变，链上仅需乘固定符号，随后通过R和叉积回到顶点。

叉积范数的单位是世界长度的平方，固定常数c引入了世界尺度依赖。
这项数学观察并不自动说明它在具体数据中重要；真实触发范围需另外统计。

## 4. 辅助图

固定贡献次序，w_i=T_i*a_i、z_i为相机空间三顶点均值深度，n_i为上述带符号法线。

```
accum_alpha = sum_i w_i = 1-T_final
raw_depth = sum_i w_i z_i
raw_normal = sum_i w_i n_i
median_depth = z_(last contributing i whose incoming T_i > 0.5)
m_i = 100/99.8 * (1 - 0.2/z_i)
distortion = sum_(i>j) w_i w_j (m_i-m_j)^2
```

median 在已固定的选中分支内只对该深度求导；它并非通常统计定义下对连续密度求出的中位数。
distortion 的两两求和与 native 的一阶/二阶矩递推在实数中等价。独立NumPy验证使用两两
公式，减少与待核验代码共享同一实现的风险。float32矩递推仍有消减误差，不能从代数等价
推出浮点实现精度相同。

早停也作为分支条件处理：当 T*(1-a)<1e-4 时，当前项与后面项均被跳过；不把当前项先
合成再停。检测阈值切换点本身不在普通导数结论内。
