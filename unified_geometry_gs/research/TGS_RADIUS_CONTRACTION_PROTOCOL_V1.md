# 冻结候选 v1：用局部坐标下的已有边梯度重建半径项

状态：候选的实数代数恒等式已手工推导，**尚未实现、运行或建立新颖性**。
本协议在观察候选精度/性能结果之前冻结，不可在原文件上改门槛；后续修订须新版本。
当前一般窗口修正额外需要每个参与像素一次 log-radius atomicAdd，真实视角反传API延迟增加
约3.7%–6.8%。本候选只针对这一成本，不改变前向、损失、三角形数或上游梯度。

## 1. 恒等式与稳定性风险

每条有向边写成 phi_k(x)=n_k·x+b_k，b_k=-n_k·a_k。
令 beta_x=dL/dphi(x)，只在被选中的max边上分配。正确分配的活跃边权重之和为1，饱和
局部链式导数为0；这些条件与已核验的piecewise模块一致。

已有边VJP为 G_k=sum_x beta_x*x、B_k=sum_x beta_x。
由于 beta_x*phi_x=(dL/dalpha_x)*sigma*alpha_x，有

```
Gamma := dL/dlog(r) = -sum_k (n_k·G_k + b_k B_k).
```

因此实数算术不必另外逐像素累积Gamma。但直接用全局像素坐标收缩，可能把大数相减，
尤其当像素坐标远大于内切半径时；不能仅凭代数等价宣称float32可靠。

选择已缓存的投影中心c。令局部VJP Gc_k=sum beta_x*(x-c)，局部偏置
bc_k=n_k·(c-a_k)。则相同标量可写为

```
Gamma = -sum_k [n_k·Gc_k + bc_k*B_k].
```

对边法线继续回传时，原来 G_k-a_k*B_k 可直接替换成

```
Gc_k + (c-a_k)*B_k.
```

这样不必先恢复大坐标的G_k。c即使依赖顶点，也不额外产生新路径：表示变换中
n·(x-c)与b+n·c的dc项相互抵消。它是同一个VJP的代数重排，不是停止一种物理依赖。
顺逆绕序下原始法线/偏置与其上游协向量应同时应用相同符号，不能只翻转其中一方。

该候选保留已有Gx/Gy/B三次原子累加，用局部坐标改写其值，并在每三角形阶段重建Gamma，
删除额外的Gamma原子加。第一版保持原临时buffer分配，以便把计时差归因于计算改写。
颜色、SH、depth和normal直接路径及前向全部保持不变。

这只是代数证明，不是浮点误差上界。局部坐标仍可能受细长三角形、混合符号梯度和累积
消减影响，必须通过下述检查；不能在结果出来后放宽精度门槛。

## 2. 精度和功能门槛

- 重跑既有18个冻结场景：九个RGB/SH/真实子集和九个分段/辅助图场景。
  使用原有门槛，保留零梯度和max不变性约定；前向整图必须逐像素相同。
- 增加图像位置/尺寸/细长形状压力检查，固定随机种子142909，在执行前生成并保存48份
  输入：W从256/2048/8192、内半径从1.25/2/8/40px、非退化细长比从1/4/8选择，
  支持区放在左侧/中部/右侧，正反绕序，正深度针孔相机。
  选样只按几何和可微分支间隔，不读取候选VJP误差。保存全部选样拒绝记录及最终输入。
- 使用混合正负像素权重与八个固定种子的上游VJP，不只测试同符号和接近原点的情况。
- 除max平局独立不变性外，非零梯度组相对L2误差必须<=1e-3，零梯度组最大绝对误差<=1e-6；
  仍需双精度/独立NumPy依据和多步长原生差分，披露其各自浮点精度。
- 新压力案例中若精度不满足门槛，v1不得作为稳健替代版本推进训练；不能删案例或收窄
  图像位置范围来把失败改写成成功。若旧版本也失准，应一起记录并追查前向/反传误差来源。

## 3. 性能门槛

精度门槛通过后，使用与 `tgs_backward_cost_v1` 相同公开完整checkpoint、两个train相机、
全图固定上游梯度、debug=False及计时口径。候选、旧piecewise与control三者采用每相机
18次平衡交错调用及每组合3次预热，在无插桩构建中计时。

推进条件：两个视角中，候选相对旧piecewise的反传墙钟配对中位比均<=0.97，且会话内
描述性bootstrap95%区间上端均<1；前向+反传调用对的配对中位比均<=1，Torch分配峰值不增加。
这是固定算子成本门槛，不等同于完整训练提速。若未通过，保留数学恒等式及负结果，v1不作为
已验证效率成果推进，也不通过减少三角形/像素/精度改变工作负载。
