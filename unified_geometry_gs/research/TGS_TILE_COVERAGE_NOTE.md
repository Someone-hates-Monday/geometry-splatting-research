# 连续三角窗口的像素tile覆盖：上界反例与修正条件

这是固定源码的数学/实现补充；几何恒等式本身为普通仿射与整数算术，不构成新颖性认证。

## 1. 取整必须对应整数采样点

设块宽B为正整数，连续支持域最大坐标M>=0。可能有效的最大整数像素为floor(M)，其块
编号为floor(M/B)，所以保守的**排他**上界为U=floor(M/B)+1（再截断到grid）。

源码使用L=floor((M+B-1)/B)。令M=mB+t、0<=t<B，可得

```
0 <= t < 1: L=m,   U=m+1
1 <= t < B: L=m+1, U=m+1
```

因此，当支持域刚进入一个新块的首个像素条带时，原公式可能把这个块排除。
该公式不能把整数半径场景中的裕量直接移用于连续浮点交点。下界和负坐标转换还需单独审查；
本轮因果干预只改四处上界，没有声称修正全部binning情况。

## 2. 精确有理反例

三角形A=(317/8,124)、B=(365/8,124)、C=(317/8,257/2)，是边长6、9/2、15/2的直角三角形。
其内半径r=3/2、内心s=(329/8,251/2)。取sigma=1、opacity=1/2。

在alpha>=1/100的内缩三角中，顶点为s+(49/50)(q-s)，最大y为3211/25=128.44。
块高16时原上界为8、正确排他上界为9；像素(40,128)位于第8块，仍处于支持域内部。
该像素三条外法线距离为-4、-7/40、-3/8，所以

```
alpha = (1/2) * ((7/40)/(3/2)) = 7/120 > 1/100 > 1/255.
```

这是严格大于两个截止值的唯一最大边样本，不是阈值或max平局造成的歧义。
Fraction程序重算证书，原生CUDA复现其漏采样；仅改上界后恢复该像素。
CPU名义1e-7投影分母与原生float32舍入使数值参考略偏离理想有理投影，约0.0583342；
这个微小偏移不影响覆盖反例，不能将其与漏采样产生的零输出混为一谈。

## 3. 三角窗口的等值支持域

设P={x:phi_i(x)<=0}，phi_i为单位外法线距离，内心满足phi_i(s)=-r。
窗口u=-max_i phi_i/r、alpha=min(.99,o*u^sigma)。对0<tau<=o、tau<.99、sigma>0，令
u0=(tau/o)^(1/sigma)，则

```
{x:alpha(x)>=tau} = {x:phi_i(x)<=-r*u0, all i}
                 = s + (1-u0)*(P-s).
```

证明：phi_i是仿射函数，把x=s+(1-u0)(y-s)代入即得
phi_i(x)=(1-u0)phi_i(y)-r*u0。反向变换同样成立（u0=1时退化到内心）。
这给出从三顶点直接计算支持AABB的方式，不必求三个近乎平行偏移直线的交点。

若要覆盖kernel实际允许的所有样本，tau须和逐像素截止值一致；本轮原生预处理用.01，
而kernel用1/255，本轮仅改上界的版本**没有消除两者差异**。
实数保守覆盖也不等于IEEE浮点下的无条件覆盖证明；仍需外向舍入/误差界或明确保护裕量。

## 4. 后续数值问题

压力集中还出现约3.7e-5–6.0e-5的共同CPU64/原生前向差，尚未按运算逐项归因。
全局像素坐标、投影分母和内心/边偏置的浮点算术均可能贡献。下一版本应单独验证局部
坐标及高精度预处理，并保留现有全部输入和门槛；不能通过删大坐标案例恢复通过状态。
