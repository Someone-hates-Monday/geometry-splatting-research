# 真实 TGS 细分事件的冻结诊断协议

2026-10-20执行状态：v1已在官方stump7000模型上完成8事件×4相机×3appearance。
结果见`TGS_REAL_EVENT_RESULT_2026_10_20.md`。按模型发布字段和load()语义还原，
属于真实checkpoint上的离线模拟；捕获训练事件及完整状态仍未取得。下方是执行前协议，
保留输入门槛和结果解释限制，不再将全部内容标作待执行。

2026-10-20。承接已完成的数学和固定输入 CUDA 核验。本文件不代表已取得 checkpoint，
不授权或启动完整训练；用于在来源可核验的真实状态上验证合成现象的实际影响。

## 输入门槛

记录 checkpoint URL/本地路径、字节哈希、场景、迭代、训练相机划分、模型格式、来源版本、
实际生效 opacity/mask/sigma/SH degree 与 renderer 配置。没有优化器状态的 PLY 可以用于
冻结渲染，但不能称为可精确恢复训练的完整状态。不得把导出的表面 mesh 当作 TGS 基元。
官方预训练目录只作为待核验来源，不推定其中含所需状态或训练配置。

事件优先取真实程序根据完整配置选中的 split 候选，保存选择前/后参数和 ID 对应。
如果只能从 PLY 离线应用固定规则，应称“真实 checkpoint 上的模拟事件”，不是捕获的训练事件。
不按渲染误差大小挑事件；保存全部合格事件 ID，再用固定哈希顺序抽样至最多32个。
相机固定：训练/保留视角分别记录；统一选择规则，不因观察结果更换。

## 有限执行

先用1场景、至多8相机、最多32事件，每次只改变一个事件，no_grad，无优化器更新。
每个输入先作原始重复渲染并同步，记录误差基线。使用原始/SH修正 × split前/后四个条件；
常量 appearance 子实验单独隔离窗口/采样/尺寸剔除，SH和排序诊断另存。
校验四个子顶点、sigma、实际opacity、mask、SH复制和祖先 ID；保证其它基元逐字节不变。

对每事件/相机记录 parent/child 可见性、屏幕面积/内切半径、近面/视角/tile剔除、
理论连续质量/重心、原生 alpha/颜色/深度变化、视口内覆盖、相机中心深度排序。
保留原始图与差图，原始数组可直接重算指标。把零输出、完全遮挡和无覆盖区别记录。
报告全部事件的分布及按几何尺寸预定义分层；样本量是事件/相机，不能把像素当独立重复。

## 判读门槛

首先验证参数重构和重复性；失败时停止效应解释。确认在真实状态中是否存在合成诊断的机制，
并报告频率/量级。不能因只存在一个显著事件就声称普遍有效。
固定模型的 SH修正可能改变原来已学到的补偿，零步 PSNR 变化只描述兼容性，不证明训练收益。
本阶段不能支持几何/图像质量提升或训练加速结论；这些需要后续公平训练、消融和评估方案。

下一研究候选应预测：在相同基元预算和渲染配置下，能降低哪些真实事件扰动、保留哪些容量，
并明确失败条件。纯 opacity 共享修正的普遍精确保持已被本轮有限透视反例排除，应考虑超出
该参数族的方案。已有 barycentric/边界核/剔除研究必须作为对照，不能把这些通用思路包装为首次提出。
