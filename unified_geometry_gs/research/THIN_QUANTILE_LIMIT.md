# 薄层中位深度：位置极限需要一重裕量，梯度极限需要两重裕量

2026-10-13。以下是固定有限一维射线模型的数学补充，非三维重建质量结论。
GGGS使用连续透射率分位根；2DGS的论文与实现采用离散可见层选择。
本说明只比较对应的射线深度规则，不等同两个完整渲染器，也不等同三角形footprint。

## 假设与记号

固定有限N、互异有序峰位p₁<…<pN，0<αᵢ<1，sᵢ>0，σᵢ=εsᵢ、ε↓0。
定义βᵢ=1−αᵢ，C₀=1，Cᵢ=∏k≤iβk；Tε为当前LaTeX中定义的GGGS连续乘积。
q∈(0,1)固定且C_N<q，tε为唯一有限分位根。相机投影、每像素α、排序均冻结。
令Fε=−log Tε；各层斜率为

    fᵢ′(t)=|t−pᵢ| αᵢ exp(−(t−pᵢ)²/(2ε²sᵢ²)) /
            [2ε²sᵢ²(1−αᵢ exp(−(t−pᵢ)²/(2ε²sᵢ²)))].

在Fε′(tε)>0处，位置Jacobian权重wᵢ=∂tε/∂pᵢ=fᵢ′/Σk f_k′。
故wᵢ≥0、Σwᵢ=1；这只对冻结的峰位参数成立，不是所有三维参数梯度的凸组合。

## 定理：严格跨越与非临界梯度极限

若某j满足Cⱼ<q<Cⱼ₋₁，令r=q/Cⱼ₋₁，β=βⱼ。定义

    z₀ = −sqrt(−2log((1−r²)/αⱼ))，当 sqrt(β)≤r<1；
    z₀ = +sqrt(−2log((1−(β/r)²)/αⱼ))，当 β<r≤sqrt(β)。

则(tε−pⱼ)/(εsⱼ)→z₀，特别tε→pⱼ。
若还满足q≠Cⱼ₋₁sqrt(βⱼ)，则z₀≠0。令Δ为最小峰间距、smax=max sᵢ，
可取c=Δ²/(8smax²)>0，使充分小ε满足

    tε = pⱼ + εsⱼz₀ + O(ε exp(−c/ε²)),
    wᵢ = O(ε⁻¹ exp(−c/ε²))，i≠j；
    wⱼ = 1 + O(ε⁻¹ exp(−c/ε²)).

N=1时没有非主层项，根公式精确，位置权重恒为1；无需定义Δ。
常数依赖固定输入；不能在两种裕量趋于零时自动作统一界。

证明：在t=pⱼ+εsⱼz、z位于任一固定有界区间时，其他峰与t的距离
对充分小ε至少为Δ/2。之前层的Tᵢ趋于βᵢ，之后层趋于1，且误差为
O(exp(−c/ε²))。所以Tε=Cⱼ₋₁ψαⱼ(z)[1+O(exp(−c/ε²))]，其中ψ是
单层无量纲透射率。ψ严格递减，r严格位于(β,1)保证唯一有限z₀；用z₀
两侧的固定点夹住根，得缩放根收敛。非临界时ψ′(z₀)≠0，局部逆映射
Lipschitz，得指数缩放根误差。此时主层斜率下界为正数/ε，其他层斜率为
O(ε⁻² exp(−c/ε²))，取比值得权重结论。该证明只用实数算术和固定有限模型。

两个需要区分的裕量：

- 平台裕量min(Cⱼ₋₁−q,q−Cⱼ)>0，保证分位根选择同一层并收敛到其峰位。
- 峰值裕量|q−Cⱼ₋₁sqrt(βⱼ)|>0，排除主层缩放根落在零斜率峰值，
  支持位置Jacobian的one-hot极限。第一项不蕴含第二项。

## 反例一：有限厚度下处处正则，梯度极限仍不集中到所选层

取p=(−1,0,1)，α=(1/5,39/64,1/5)，s=(1,1,1)，q=1/2。
C₁=4/5、C₂=5/16，严格跨越成立；内部峰值恰满足C₁sqrt(β₂)=1/2。
设E=exp(−1/(2ε²))。在t=0，左右vacancy因子相消，Tε(0)=1/2，故
tε=0对所有ε>0成立。因三个峰互异，根处斜率

    Fε′(0)=E/[5ε²(1−E/5)] > 0，

所以每个有限ε的根都是正则根；不是拿未定义的IFT导数作反例。
中层峰值的f₂′(0)=0，两外层斜率相同，因此

    (∂tε/∂p₁, ∂tε/∂p₂, ∂tε/∂p₃) = (1/2,0,1/2)。

根始终等于中层峰位，位置Jacobian却从不趋于中层的one-hot向量。
同时，中层opacity导数精确为

    ∂tε/∂α₂ = −(32/5) ε² [exp(1/(2ε²))−1/5]，

随ε↓0指数发散。该例说明对固定参数的深度极限不能与参数微分随意交换，
并展示非临界裕量对统一敏感性控制的作用。不证明训练轨迹会落在该对称集合；
rounding、opacity扰动或实际GPU梯度floor都会改变实际行为。

## 反例二：平台等号时，根可永久位于两层之间

取双层α₁=α₂=1/2、q=1/2，p₁<p₂，σᵢ=εsᵢ。
此时q=C₁，严格跨越条件不成立。在两峰之间，Tε=q等价于两层的
归一化距离平方相同，故对每个ε>0都有

    tε=(s₁p₂+s₂p₁)/(s₁+s₂)。

这是严格的中间点，不趋于任一层峰位；等宽p=(−1,1)时根恒为0。
有限根依旧唯一且正则。离散可见层规则的等号约定不能自动复现此极限。
