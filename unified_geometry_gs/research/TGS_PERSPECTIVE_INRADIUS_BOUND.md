# 透视中点四分的内切半径锐下界

2026-10-20。由真实 checkpoint 的跨视角子三角形剔除现象引出的数学补充。
证明与程序核验分开记录；不声称已有独立同行审核或完成新颖性检索。

## 命题与条件

三维非退化三角形经理想针孔投影得到非退化像平面三角形K。三个顶点的齐次投影分母
z_i均为正；固定该视角，令 kappa=max z_i/min z_i>=1。在世界空间连接边中点进行四分。
设父像平面内切半径r，四个子像平面内切半径r_j，则

    min_j r_j >= r/(1+kappa).

这个统一常数是锐的。kappa=1时恢复像平面中点四分r_j=r/2。
这是每个视角的几何结论，不保证通过 opacity、近平面、角度、tile 或大尺寸剔除，
也不包含遮挡、SH、排序、浮点舍入和图像质量。

## 证明

令 a=1/(1+kappa)，b=kappa/(1+kappa)=1-a，K的顶点为v_i、周长L、面积A。
世界边ij中点的投影为

    m_ij = (z_i v_i+z_j v_j)/(z_i+z_j).

所以它在对应像平面边上，沿任一方向的边参数都落在[a,b]。

**角部子三角形。** 对角i，两个边参数均至少a，所以子三角形包含
`v_i+a(K-v_i)`。凸集包含关系下内切半径单调，直接得r_i>=a r。
这里使用内切半径定义为可放入的最大圆半径，不需要近似相似性。

**中心子三角形的面积。** 面积比可在标准三角形上按行列式计算（一般三角形的面积比
在同一可逆仿射映射下不变；这里未声称内切半径仿射不变）：

    A_c/A = 2 z_1 z_2 z_3 / [(z_1+z_2)(z_2+z_3)(z_3+z_1)].

把最小/最大深度归一为1和kappa，剩余深度记t in[1,kappa]。分母除以深度乘积得

    Q = 2+kappa+1/kappa+(1+1/kappa)t+(1+kappa)/t.

Q关于t为凸函数，因此区间最大值在端点；两端均为`2(1+kappa)^2/kappa`。
故`A_c/A >= kappa/(1+kappa)^2 = a b`。

**中心子三角形的周长。** kappa>1时，每个边点可写为

    m_e = (1-2a) p_e + 2a q_e,

其中q_e为该像平面边的普通中点，p_e仍在该边上。令P为三个p_e的凸包，M为普通中点三角形。
中心子三角形C包含在Minkowski和`(1-2a)P+2a M`中。利用平面凸集周长的包含单调性，
以及Minkowski和的周长可加性（由Cauchy投影宽度积分直接得到），有

    L_c <= (1-2a) L(P)+2a L(M)
         <= (1-2a)L + 2a*(L/2) = b L.

对退化P采用凸体周长的连续延拓，结论不变。kappa=1时直接使用普通中点三角形。
这里用到的标准引理可直接由支持函数核对：`h_(sP+tM)=s h_P+t h_M`，
`Per(P)=integral_0^(2pi) h_P(theta) dtheta`。包含关系给出支持函数逐点不等式，
所以同时得到周长单调性和Minkowski可加性。已核读作者大学站讲义
[Treibergs, Mixed Area and the Isoperimetric Inequality](https://www.math.utah.edu/~treiberg/MixedAreaSlides.pdf)
第15、17页（PDF页码），这些经典凸几何工具不属于本文的新颖性主张。
因为三角形r=2A/L，中心子半径满足

    r_c/r = (A_c/A)/(L_c/L) >= (a b)/b = a.

合并四个子三角形即得命题。

**锐性。** 固定任一非退化像平面三角形，取z_1=kappa、z_2=z_3=1，对应三维顶点
由其像平面坐标和深度反投影构造。这三个点定义非退化三维三角形。
角1的两个中点投影参数恰为a，故其子三角形正是`v_1+a(K-v_1)`，r_1=a r，等号成立。

## 对本次原生尺寸剔除的含义

若原生规则只看`r_child<1 pixel`，理想几何中的一个充分条件是

    r_parent >= 1+kappa  pixels.

实作应留出浮点裕量，不能用数学等号直接保证单精度边界分类。条件不成立表示“不能由此保证”，
并不表示子三角形一定会被剔除。它应逐视角检查，不能把某个视角较大的屏幕外接尺寸当作全视角保证。

真实stump7000的parent16010在测试视角0外接半径30像素，因而进入预定义候选；
在训练视角2外接半径20像素、内切半径约1.80092像素，四子均被原生renderer剔除。
`verify_tgs_inradius_bound.py` 对该事件重新计算正深度、角度和四子内切半径，
把尺寸原因与其它预处理条件区分检查。该事件是冻结模型上的模拟操作，不是捕获的训练日志事件。

## 核验范围

程序使用SymPy核对中心面积式、Q的二阶导数和端点值；以固定seed检查1500组随机几何/正深度，
并检查kappa=1,2,10,100的精确等号构造。随机一致性不能代替上面的全称证明。
另对本轮31个正深度实际投影进行核验，并单列world midpoint浮点舍入后的值。
结果在`experiments/tgs_real_event_v1/inradius_bound_checks.json`。

该结果可以作为有理论保证的尺寸风险检查，但还不是已验证的训练方法。
直接拒绝所有有风险的细分会改变基元容量和探索过程；若研究具体策略，必须记录拒绝率，
并与相同新增基元预算的替代细分比较，不能把“保留父基元所以图像没变”当作优化成功。
