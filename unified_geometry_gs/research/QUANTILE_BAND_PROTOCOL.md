# 分位区间均值：条件稳定性与深度偏差核验方案

2026-10-13。记录于本方案数值核验前。接续薄层极限反例；不启动训练，
不修改生产 CUDA，不扩大未通过门槛的 factor64 留出实验。

## 对象与待证明结论

沿用固定有限一维 GGGS 透射率 T(t)，0<alpha_i<1、sigma_i>0。
固定 C_N < q_l < q_u < 1，h=q_u-q_l，定义

    M = (1/h) integral_[q_l,q_u] t(q) dq.

这是已有的区间分位均值 / trimmed quantile mean 思想，不能作为新统计量声称。
候选贡献仅是本射线模型中的正则性、梯度界及薄层代价的具体证明。

待验证：

1. 对局部共同固定的有限 bracket [a,b]，有
   M=a+integral_[a,b] clip((T(t)-q_l)/h,0,1) dt。
   该深度泛函在参数内部 C1，包括某个区间内分位根为临界根的情形。
   参数梯度为 integral_{q_l<T<q_u} T_theta(t) dt / h；不除以 T_t。
2. 对冻结峰位参数，位置偏导非负且和为1；对 opacity，
   |M_alpha_i| <= (b-a)/(h(1-alpha_i))，不依赖根处斜率正下界。
   此界只对具有共同有限 bracket 的参数邻域有效；h->0 或 alpha->1 无统一界。
3. 固定互异峰位、sigma_i=epsilon s_i 的薄层极限为
   sum_i p_i length([q_l,q_u] intersect [C_i,C_{i-1}]) / h。
   区间完全位于某一层跨越时保留该层；跨平台时会产生混合深度。
   因而稳定梯度不免费保证表面保真或三维重建质量。

## 固定数值案例与门槛

- 沿用 p=(-1,0,1)、alpha=(1/5,39/64,1/5)、s=(1,1,1)，
  epsilon=(.5,.35,.25,.2,.15,.1,.075)，区间[.45,.55]。
  采用独立实空间积分计算 M 与直接 T_alpha 积分；梯度中心差分重新积分。
  位置梯度分量非负、和1误差<=1e-8；所有 opacity 梯度均满足上述解析界。
  opacity 差分步长固定1e-6（不是单根反例的指数小步长），
  相对 / absolute floor 1e-8 误差<=1e-5；保存全部结果与误差。
- 单层 p=0, alpha=3/4, sigma=.2，区间[.45,.55]包含 q=.5 的
  临界根。验证空间积分给出的有限梯度，且不调用单根的无定义 IFT。
- 平台例 p=(-1,1)、alpha=(1/2,1/2)，s=(1,1)和(1,2)，
  epsilon=(.5,.2,.075)，区间[.45,.55]。验证薄层深度趋于0而非某一表面；
  等宽时单根和区间均值可同为0，不把位置偏差减少普遍化。
- 跨平台非对称区间[.40,.55]与同一两层参数；薄层预测 -1/3，
  最薄点的误差仅记录，不为通过而改动参数或门槛。
- 两种独立前向：实空间 clipped-T 积分 vs 分位空间重新求根积分。
  在最厚 epsilon=.5 的三层例以及单层临界例对比，绝对误差<=1e-8。
  高精度/自适应积分成本仅诊断，不声称 CUDA 性能提升。

数值实现需显式处理层峰位、区间端点与自适应积分误差；若失败，保存失败源码、
日志与输出，不把优化积分精度或 bug 修复当新的研究成功。
结果只佐证解析证明。不存在真实数据质量、完整渲染器、显著性或新颖性结论。

## 已发现的相关工作与边界

GGGS https://arxiv.org/html/2601.17835v2 已使用连续深度和隐式梯度。
区间分位均值在风险度量中的先例需明确引用，例如

https://rama.cont.perso.math.cnrs.fr/pdf/RobustRisk.pdf 。
