# TGS 反传修正：遮挡、SH 混合路径与真实 checkpoint 子集验证

本轮完成了上一阶段修正的两项必要扩展：固定三层遮挡合成及 SH 几何混合路径，
以及公开真实 checkpoint 的两个重叠三角形子集。五个修正版场景均通过预先冻结的门槛。
这是反传正确性证据，**尚无真实训练质量、重建精度、耗时或论文新颖性结论**。

## 1. 三层合成与 SH

冻结三个深度分离、绕序混合的三角形，320×192 图像、非零 RGB 背景、四个整数像素及
固定正负 RGB 权重。三种外观（常量色、SH1、SH3）共用同一几何，不是三个独立场景样本。
全部输入、方向探针及门槛写入 `experiments/tgs_mixed_backward_v1/protocol.json` 后才运行 CUDA。

使用上轮只修 SH 构造的控制模块和完整几何修正模块；直接只读加载已编译 .so，不重写旧
build receipt。三张完整输出在控制/修正版间均逐像素相同，实际保存了
**810 个探针×步长对照**。

测试每个几何/sigma/opacity 坐标、每三角形两项 SH 系数以及八个固定稠密方向，
用 h=.01、.003、.001 做中心差分。全部 SH 系数的 VJP 同时与独立解析参考比较，
但未声称对每个 SH 系数逐个做了原生差分。全部正负扰动的 active edge、颜色 clamp、
alpha cap、排序及贡献/早停分支一致。

结果（相对 L2 梯度误差）：

- 常量色：控制几何 0.989332，修正后 3.505e-7。
- SH1：控制几何 0.986556，修正后 3.722e-7；SH 系数误差 2.707e-7。
- SH3：控制几何 0.978371，修正后 3.181e-7；SH 系数误差 3.639e-7。

原生采样 RGB 与 float64 公式最大差 8.101e-8。在预设差分步长 .003 下，原生 FD 与参考
方向导数的联合相对差分别为 9.580e-5、1.363e-4、1.366e-4。它们不是解析梯度误差本身。
独立 Windows NumPy 复步长结果与 Torch autograd 的差不超过 5.334e-16。
旧阶段封存的 40 个证据文件也确认未被重新加载模块的过程修改。

## 2. 真实模型输入、选择规则与裁剪

公开 stump iteration7000 checkpoint 的 SHA256 仍为
`9898fce495a105f0aa3fed9f0cbb181a68b1438c5eab046b62c9ab0f55a73620`，共784056三角形。
本轮只取此前固定的两个训练相机 `_DSC9258`、`_DSC9322`，每相机四个重叠三角形、
三个整数采样像素。没有使用 GT 图像、test 视角或优化器，也没有更新模型。

候选依据旧完整前向可见性、投影几何和光滑分支间隔筛选，按固定 SHA256 排序选锚点；
要求四者在三个像素均有贡献，深度间隔>0.02、alpha在[.03,.9]，远离边和颜色 clamp。
最多64锚点及三个固定偏移，保留了5条进入重叠集合选择的尝试记录；前置几何筛除未逐项保存。
选择过程中没有观察 VJP 对照结果；这些筛选使本实验不代表整场景分布或边界行为。

实际 ID：

- `_DSC9258`：594049、128469、627443、777655。
- `_DSC9322`：118660、461181、111、22895。

在原1245×825相机中取128×128裁剪，保持像素尺度；不是把完整图缩小到128×128。
对齐投影时还处理 native 分母的1e-7，float32投影矩阵导致的最大顶点偏差为
2.054e-5px、9.617e-6px。完整原投影、裁剪原点和全图采样坐标均保存，可独立复算。
子集比对确认所有顶点、activated sigma/opacity 和全部 SH3 系数均逐位来自原 checkpoint。
真实训练mask/优化器历史仍不可获得；采用此前核验的公开 load() 推理语义，未验证训练mask梯度。

真实输入在 `experiments/tgs_real_backward_v2`，协议也在首次 CUDA 调用前冻结。
v1 只在只读张量转换时退出（checkpoint 带 requires_grad），未调用 CUDA；失败堆栈和
当时脚本保留，改成 detach 快照后使用 v2 新目录完成，未删除失败证据。

## 3. 真实子集结果

- `_DSC9258`：控制几何误差0.984361，修正后 **8.168e-7**。
- `_DSC9322`：控制几何误差0.984580，修正后 **1.638e-6**。

两子集中 sigma/opacity 联合误差<=1.420e-6，SH 系数误差<=1.161e-6。
控制/修正的两个完整裁剪 RGB 输出均逐像素相同；与CPU参考采样RGB差<=9.173e-8。
全批正负扰动保持相同贡献分支和 native 可见性，未剔除差分失败案例。

预设 h=.0003、.0001、.00003；规则允许仅按 CPU 分支稳定性预先减半，但本次均无需减半。
每子集测试44个几何/sigma/opacity坐标、8个SH坐标及8个稠密方向，两版本共
**720 个探针×步长对照**。在中间步长 .0001，原生 FD 误差约0.3044%、0.09892%，
CPU FD误差1.336e-7、7.128e-7；独立复步长与autograd差<=1.061e-15。
浮点差分精度明显低于解析 VJP 比较，不能把它们混为一种精度指标。

## 4. 独立核验与程序入口

新推导 `TGS_MIXED_BACKWARD_DERIVATION.md` 说明遮挡尾部合成、非零背景及 SH 均值方向
导数如何与完整窗口导数相加。它是普通微积分的补全，不声称推导本身已具备新颖性。

独立 NumPy 使用带符号面积/周长和 SH 多项式的复步长求导，不加载 Torch/native。
重算全部 CPU 正负损失、贡献分支、实际 float32 扰动路径及保存的原生采样损失。
额外只读 CPU 审计用 weights_only=True 加载 checkpoint，核对所有子集参数。
门槛按保存的组误差、前向差、固定中间步长及分支条件重算，未只信 gate 布尔值。

## 5. 下一门槛及科研判断

目前修正已跨过合成单三角形、固定遮挡、SH1/3耦合及两份真实参数子集，但仍不能推断
整场景训练正确或质量提升；这也不直接解释GGGS旧负实验，代码路径不同。

下一步应把 alpha 饱和、max ties 和早停的导数约定单独核验，再验证 depth/normal/median/
distortion 辅助输出。随后才具备冻结训练对照的基础。尤其需要区分精确梯度与有意采用的
代理梯度；在数学上补齐导数不保证原训练学习率或优化轨迹更好。

最终训练评估还需控制SH修正、像素缩放、半径链式项及学习率补偿，并用真实 held-out
图像/几何与耗时检验，而不是仅以梯度测试通过代替研究成功。本轮没有扩大完整训练授权。
