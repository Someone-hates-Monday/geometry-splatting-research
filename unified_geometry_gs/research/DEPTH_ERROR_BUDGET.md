# 深度求根误差如何进入 TSDF：条件性预算

2026-10-12；本说明为标准括区与 Lipschitz 性的补充推导，不主张新颖性。
目的：把归一化求根容差与 voxel、truncation 和几何影响联系起来，
而不是仅凭 GPU 时间或最大深度差采纳新求解器。

## 1. 连续模型中的细分界

若初始区间 [a,b] 确实含唯一根，8 等分每轮保留含根子区间，
n 轮后区间宽度 L_n=(b−a)/8ⁿ。返回区间内任意点，绝对误差≤L_n；
返回中点则≤L_n/2。这是精确算术结论，浮点端点判号另需误差分析。

本项目初始 ±0.4，故 L₄=0.0001953125，L₅=0.0000244140625，
单位为归一化射线距离。相机 z 深度等于射线距离除以 ray_length≥1，
所以 z 深度误差界不更大。
voxel=0.002 时，四轮区间内返回值的保守界约为 0.0977 voxel，
五轮约为 0.0122 voxel；线性插值的实际误差通常小得多，但不能由此直接保证。

给定相机深度预算 ε_z，保守细分轮数可按
n≥ceil(log₈((b−a)/(ray_length·ε_z))) 选择。
该式依赖有效括区，不能用于被原门控拒绝或不含根的射线。
当前已安装 CUDA 使用 float32 与 fast math，因此上述算术界不能
未经符号误差控制就称为生产实现的严格保证。

## 2. 固定融合支持下的 TSDF 值界

设每视角使用 s_i(x)=clip((D_i(π_i(x))−z_i(x))/μ,−1,1)。
相同像素对应、融合权重和有效集合下，若 |D̃_i−D_i|≤ε_i，
clip 是 1-Lipschitz，故 |s̃_i−s_i|≤ε_i/μ。
对非负权重 w_i 的归一化融合 f=Σw_i s_i/Σw_i，
有 |f̃−f|≤Σw_i ε_i/(μΣw_i)≤max ε_i/μ。
若保存的是物理距离 μf，则其误差界为 max ε_i。

若沿某法向线段两场的零点存在且原场单调、|∂_n f|≥m>0，
则对应根位移≤max ε_i/(μm)。证明是把扰动后根代入原场，
利用值界及中值定理。缺少单调区间、根存在或正梯度下界时，不得使用此式。

## 3. 为什么仍必须重提取并评估

Open3D 的 block 激活、截断带的有效样本、可见性、插值、marching cubes、
最大连通簇和拓扑选择会随深度变化；上述固定支持假设可能失效。
窄缝、薄层和低梯度区域尤其不能由很小的逐像素误差推出相同拓扑。
没有 Hausdorff/Chamfer 的无条件界，也没有质量保持保证。

四轮与五轮的完整掩码一致，只覆盖渲染可见性这一部分；
后续六次冻结网格提取和相同种子 DTU 评估用于直接检验实际代价。
如果几何门槛失败，保留结果并拒绝按当前协议采纳四轮控制。
