# SH 中心迁移的有限阶误差：固定半径球面上的补充证明

2026-10-21。本文使用标准 Legendre/SH 工具，尚未建立新颖性。它补充 v12 的两相机反例，
不是实际 PSNR 下界、完整渲染保持定理或训练收益证明。精确恒等式由
`verify_tgs_sh_shell_v13.py` 用 SymPy 1.14 核验，另有独立 mpmath 原坐标积分。

## 1. 距离相同仍不消除有限阶表示障碍

令新中心 p、旧外观中心 q=p+aR v，R>0，0<a<1，||v||=1。相机遍历 c=p−Rd，
||d||=1，即到新中心的距离全部为 R。新方向为 d，旧方向为 e=(d+av)/||d+av||。
取 t=v·d，则旧 degree1 色场 v·e 变为

    f_a(t)=(t+a)/sqrt(1+2at+a²),  −1<=t<=1.

固定球面后不存在 v12 中的“相同 d、不同 r”歧义，依然不能用任意有限阶 SH 精确表示
这个函数。证明：若有有限阶表示，绕 v 做方位平均仍是有限阶表示，而且目标不变。
其平均是某个有限次数的 Legendre 多项式组合 h(t)，因而是多项式。由 h=f_a 得

    h(t)²(1+2at+a²)=(t+a)².

在开区间相等使其为多项式恒等式。左侧非零次数为 2 deg(h)+1，右侧次数为 2，矛盾。
此结论要求 a 非零且距离非奇异；a=0 时原 degree1 完全可表示。方向函数的有限阶障碍
与缺少径向信息是两个不同原因；旋转 SH 的 Wigner 矩阵不能作为中心迁移的精确解法。

## 2. 完整谱系数、最佳平方误差与一个可达上界

用 P_n(1)=1 的 Legendre 约定，f_a(t)=sum_(n>=0) b_n(a)P_n(t)，则

    b_0=2a/3,
    b_n=(-a)^(n−1)[n/(2n−1)−(n+2)a²/(2n+3)], n>=1.

证明：从标准生成函数 (1+2at+a²)^(-1/2)=sum_(n>=0)(−a)^n P_n(t) 出发，
乘以 t+a，再用 tP_n=[(n+1)P_(n+1)+nP_(n−1)]/(2n+1) 合并同阶项。
对任意固定 0<a<1，该操作由一致绝对收敛保证。n=0 单独给出上述式子。
归一化和生成函数的标准出处为 [NIST DLMF 18.12.11](https://dlmf.nist.gov/18.12.E11)。

在完整均匀相机球面上，采用归一化测度 dOmega/(4pi)，zonal 函数的平方范数是
(1/2)integral_(-1)^1 f(t)²dt，且 ||P_n||²=1/(2n+1)。因此阶数不超过 L 的任意 SH
近似 H（允许非轴对称项）都满足

    ||f_a−H||_2² >= sum_(n>L) b_n²/(2n+1)
                  >= b_(L+1)²/(2L+3).

第一个下界实际上是最优平方误差，投影 H_L=sum_(n=0)^L b_n P_n 取得；非轴对称项
因正交性无法改善它。SH 正交性见 [NIST DLMF 14.30.8](https://dlmf.nist.gov/14.30.E8)。
这不是对有限几个训练视角的最小二乘下界，受限视场或不均匀权重可以有不同结果。

还可准确给出上述 L2 投影自身的最大误差。对 n>=1、0<a<1，括号为正，因为在 a=1
时两分式的差仍为 2/((2n−1)(2n+3))>0。所以 b_n 的符号为 (−1)^(n−1)。利用
|P_n(t)|<=1，所有尾项在 t=−1 同号，得

    ||f_a−H_L||_infinity = sum_(n>L)|b_n|
                         = 1+H_L(−1), L>=0.

这里没有声称 H_L 是 L-infinity 意义下的 minimax 最优解。它是一个具体可实现投影的
精确最大误差，可以用作该受限问题的选阶规则，不能无条件用于任意三阶真实色场。

例：色场 C=1/2+f_a/4 在 [1/4,3/4] 内；a=1/2、L=3 时，任何三阶 SH 的全球面
单通道 RMS 误差至少为 |b_4|/12=67/14784≈0.0045319264。该投影实际 RMS
约为 0.00504804014，最大误差约为 0.02653769841。这里没有遮挡、opacity 或像素权重。

## 3. 不得把 degree1 的高阶小量推广到 degree3

若旧场是 P_l(v·e)，对小 a 在固定球面上一致展开：

    P_l(f_a(t)) = P_l(t)+a(1−t²)P_l'(t)+O(a²)
               = P_l(t)+a*l(l+1)/(2l+1)[P_(l−1)(t)−P_(l+1)(t)]+O(a²).

这是标准 Legendre 微分/递推恒等式的应用。由于 a 被限制在远离 1 的紧子区间内，
分母一致非零，一阶余项的一致性成立。脚本精确核验 l=1..8；一般式由递推证明。
最高阶已为 L 的色场会产生一阶大小的 L+1 模态，不是普遍 O(a^(L+1)) 的误差。

对 l=3，直接换元 u=sqrt(1+2at+a²)，积分区间 [1−a,1+a]，将
(9/2)integral_(-1)^1 P_3(f_a(t))P_4(t)dt 化为有理 Laurent 多项式，得到精确系数

    B_4(a)=−12a(217a^4−364a²+143)/1001.

因此任何三阶 SH 近似此旧 degree3 场的全球面 RMS 误差至少为 |B_4(a)|/3，
即小 a 时为 4a/7+O(a³)。乘色场幅度 k 后相应乘 |k|。B_4 在某些较大 a 可以为零，
不能声称这一单模态下界对整个 (0,1) 严格正；其他模态仍可能非零。
例如 a=0.1、色场 1/2+P_3(v·e)/4 的该下界约为 0.01392424575，说明只用 degree1
例子评估重参数化难度，会明显低估已有高阶外观的困难。

## 4. 一个可用于限定外观漂移的充分条件

令任意有限阶标量场 F(d)=sum_(l,m) A_lm Y_lm(d)，Y 为对面积测度正交归一的实 SH。
从加法定理对两点沿同一单位切向求导，得到

    sum_m (D_w Y_lm(d))² = l(l+1)(2l+1)/(8pi), ||w||=1, w·d=0.

对各 band 用 Cauchy-Schwarz，再沿球面最短弧积分，故

    |F(e)−F(d)| <= M*angle(e,d),
    M=sum_(l=1)^L ||A_l||_2*sqrt(l(l+1)(2l+1)/(8pi)).

这个梯度界和加法定理均是标准工具的推论，不作为新定理原创性声明。加法定理出处为
[NIST DLMF 14.30.9](https://dlmf.nist.gov/14.30.E9)。几何上，平移球面 d+av 的切线
给出最大夹角 arcsin(a)：其 cos²=(1+at)²/(1+2at+a²)，在 t=−a 取得 1−a²。
于是 |F(e)−F(d)|<=M*arcsin(a)。对 RGB 可逐通道使用；DC 不影响 M，逐通道截断
是 1-Lipschitz，不会增加已存在的上界。此界针对实际系数，避免仅用位移当颜色误差代理。

若比较的是同一套**固定** alpha、排序和支持下的两种颜色，w_i=T_i alpha_i>=0，
sum w_i<=1，则每个像素 |Delta C|<=sum_i w_i B_i<=max_i B_i。
如还改变基元几何，alpha/排序/支持可能改变，以上式子只约束颜色分量；不能把它升级为
完整 densification 的图像保持保证。低 opacity 的线性密度混合也不等于离散 alpha 合成。

## 5. 当前核验、用途与尚缺证据

CPU 检查已 exit0：degree1 的 n=0..7 精确系数、l=1..8 一阶恒等式、degree3→4 精确系数，
以及 a={.01,.1,.25,.5,.75} 的 60 位独立原坐标积分一致。积分核验不是一般证明的替代。
第4节为上述加法定理和几何的书面证明；尚未对真实系数执行其数值紧致性或运行时检查。

这些结果使问题从“增加一个锚点”具体化为：受限选阶、保留径向/中心信息，或有界 reanchoring。
下一项有用检查是，在预先抽取的真实公开 SH3 系数上，比较复制系数、固定阶投影和更高阶
投影的外观误差，检验 degree1 示例是否具有代表性。即使通过，也仍只是色场诊断，
不能证明真实图像/几何或训练收益。常见 SH 平移工具处理带特定径向因子的调和势，
这里是仅依赖归一化方向的辐射函数；不能不检查假设就搬用其有限阶平移结论。

## 6. 不同半径的过补偿：事后机制解释

本节推导发生在距离压力结果之后，不当作预先预测的确认实验。取旧 F 的阶数至多3，
G(d)=grad_S F(d)·v，投影 P 为完整均匀球面上到三阶空间的正交投影。若 G 非零，令
eta=||PG||²/||G||²。固定原半径转换在新半径 kR 上的一阶相对 RMS 误差为

    frozen_L3 / copy -> sqrt((k−1)² eta + (1−eta)),
    frozen_L4 / copy -> |k−1|,  a->0, k>0 固定。

证明：目标在 kR 上为 F+(a/k)G+O(a²)。原半径的三阶投影为 F+a PG+O(a²)，
所以其差为 a(1−1/k)PG−(a/k)(I−P)G+O(a²)。两部分正交，而 copy 的领先误差
范数为 (a/k)||G||，相除得到第一式。

四阶空间包含 G：对每个实 SH 使用其齐次调和延拓 H_l，
G_l=v·grad H_l−l(v·d)H_l。令
K_(l+1)(x)=(v·x)H_l(x)−||x||²(v·grad H_l(x))/(2l+1)，直接算 Laplace 得零。
于是 G_l 是 l−1 与 l+1 阶调和函数之和；l<=3 时最高为4。四阶投影保留全部一阶 G，
故误差领先项为 a(1−1/k)G，得到第二式。a 足够小时所有距离非零，展开一致；
若 G=0 则不得除以它，本结论不确定更高阶的相对误差。有限 a 的误差仍以保存结果为准。

例如 k=4 时，四阶补偿的极限比为3；k=2 时三阶和四阶的极限比均为1。单一半径上
多存9个系数的改善可以很大，但并不解决径向信息不足。这一解释与压力结果一致，
仍不支持真实图像、训练或新颖性结论。
