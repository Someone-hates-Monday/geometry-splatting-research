# 精确整数倒数表：固定认证求根诊断通过效率门槛

2026-10-14。对应 `RECIPROCAL_ROOT_PROTOCOL.md`，结果 `experiments/reciprocal_root_v2`，独立记录 `results/reciprocal_root_audit_v1.json`。

## 改动与正确性

只将严格级数中六处正整数倒数改成 CUDA constant-memory 区间表，k=1..51。用精确有理数核验两个 binary64 端点包围 1/k，且端点相邻或相等，因此端点等于 IEEE 向下/向上舍入的倒数。原区间乘法、其他动态除法、级数阶数和余项全部保留。原参数、候选、预算、容差、回退与数据不改；原生产 CUDA 和训练源码未修改。

同一进程分别重编原存档对照和这个单一变体。7322 原参数层、110 数学射线模型的全部预算数组、根、分类、符号端点与 NaN 位模式逐位相同；重编对照与原 device_root_v1 也逐位相同。106 有限根保持 76 low / 30 high，4 无根保持 2 critical / 2 insufficient，无 unresolved。

独立 CPU 审核重算 51 个精确相邻倒数界，确认只改六个调用点，核对来源/产物/生成文件/ZIP 和完整数组；106 括区宽度用 Fraction 核验，两端严格符号保持正确。位一致继承上一阶段 MP240 世界参照核验，**本轮没有新增独立未观测样本或重跑 MP240**。数学根误差仍为上一阶段的最大 1.361838888e−5 camera-ray 单位，不能解释为 GT 或 world mm。

## 五对交替计时

RTX 5090 Laptop、CUDA 12.8、相同严格编译选项，预热后按 control/variant、variant/control 交替测五对。每个批次为 7322 双路径预算及 110 模型求根/证书。

- 预算 event 中位数：control 0.403200 ms，variant 0.268448 ms；配对比几何均值 0.681301。
- 根与证书 event 中位数：control 705.381042 ms，variant 384.888275 ms；配对比几何均值 0.545663。
- 合并 event 中位数：control **705.739014 ms**，variant **385.180573 ms**；配对比几何均值 **0.545837**，耗时减少 **45.4163%**，速度比 **1.83205**。
- 五对合并比范围 0.545781–0.545884；完整逐对 event/wall 记录已保存。重复批次不是独立训练种子、硬件泛化或显著性检验。

所有逐位一致检查成立且合并 event 比小于预定 0.95，**局部优化门槛通过**。计时包含输出 allocation/fill 和相应 kernel，不含 host 输入传输、完整 renderer、backward、GT 或 optimizer；385 ms 仍是高成本的严格诊断。该整数倒数缓存属于数值实现优化，尚未证明独立学术新颖性。

## 保留的失败与恢复

reciprocal_root_v1 在构建前的源码替换计数断言处失败，没有 CUDA 比较或计时。生成器误将 r/x 两个循环的匹配计数合并；修正为六个独立位置后生成 v2，未改输入、算法内容或通过门槛。v1 manifest、源码 ZIP 和 failure.txt 保留。v2 已终态 complete/exit0（session15185）。本次没有训练卡死证据。
