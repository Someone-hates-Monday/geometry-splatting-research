# v27：联合编辑可加性、零结果及全局正则项边界

2026-10-21。完成32次原生控制前向、24个真实联合候选的完整参考、独立 CPU 审计及精确符号补充。没有训练、backward、接受的编辑、新数据下载或独立质量集。

## 本轮结论

证明并核验了一个有条件的图像损失可加性结论：不同编辑的结构影响区域互不相交时，逐像素损失可加；对于11×11 SSIM，需将区域外扩5像素后仍互不相交。真实24对中，22对满足这个保守条件，全部通过全图 RGB／SSIM 逐位拼接、整数误差精确可加及浮点归约误差界检查；其中19对的两个单编辑都实际改变了 RGB，并非仅靠零案例通过。

**没有在这批真实联合候选中观察到超出舍入误差范围的图像损失交互。** 另外2对虽然外接矩形重叠，总损失交互也近于零。事后 CPU 逐像素诊断发现它们的实际 RGB 变化和 SSIM 变化区域分离，且联合图像等于分区拼接，不能把它们冒充“真实非加性已验证”的证据。

同时澄清：图像损失可加不代表完整训练目标可加。归档 TGS 的平均 opacity 正则项受基元总数影响，即使图像区域分离也存在全局耦合；本轮给出了精确修正式并通过 SymPy 核验，但没有测量实际训练中的该项收益。

## 数学条件与适用范围

设 R_i 是父基元及其四个子基元的原生 tile 所在区域的外接矩形。它是结构支持上界，不是“观察到 RGB 改变的像素集合”。要求预处理仅依赖自身参数／相机、未编辑属性固定、外部原始项相对顺序不变、原始项与新生项的深度并列规则一致、删除不同父项、每项只插入自身子项，且保持 window、alpha 截断与提前停止规则。

若 R_i 互不相交，每个像素最多见到一个编辑，联合 RGB 等于各单编辑和基线的分区拼接。逐像素 L1、MSE、PNG8 SSE 因而可加。定义 A_i 为 R_i 外扩5像素并裁到图像；若 A_i 互不相交，每个 SSIM 输出也最多依赖一个编辑，于是 SSIM 和两种图像混合形式可加。空 R 对应空 A。条件仅充分，不能把矩形重叠视为必然有交互。

多视角的固定加权目标可使用各视角冲突边的并集：无冲突的编辑集合满足各视角条件，因此该有限相机集合上的图像目标可加。但这不是未见视角、参数更新后的训练收益或全部正则项的保证。本轮没有执行独立集选择、策略更新或模型接受。

完整论证见 `TGS_JOINT_EDIT_LOCALITY_NOTE_V27.md`。它是源码条件下的有限依赖关系补充，不声称新的普遍定理，也不把有限样例当作所有 CUDA 编译行为的形式化证明。

## 冻结设计与真实参考

沿用 flowers／room 各四个 v20 父基元，仅使用 moved 模式：子基元继承相同 SH 系数，在各相机重新求值。四个已知视角每个保留全部六个无序不同父项对，共24个新联合对比。删除两个原始父项，保留其他项顺序，按预定对成员顺序追加各自四个子基元。没有按 GT 或新交互结果挑选／替换案例。

区域及结构分类在新输出前冻结：22对 R／A 分离，2对 R／A 重叠。每视角一个原始控制前向、一个16子基元预处理库、六个完整联合参考，共 `4*(1+1+6)=32` 次。库的混合图被丢弃。单编辑参考重用已封存无损图像，不重新调用原生渲染。

全部联合案例检查了未编辑可见缓存字段的 ID 重映射、两组子基元字段、基线／单编辑图像哈希、结构区域外 RGB／SSIM 不变。区域分离者进一步要求全图字节相等的拼接和 PNG8 SSE 精确相加。浮点相互作用定义为 `eta=Delta_joint-Delta_i-Delta_j`，按每例项数与绝对和计算预写的保守归约误差界。不能用数值容差补救失败的图像／图值逐位检查。

## 测量结果与独立审计

24对的 PNG8 SSE 交互全部为整数零。原始 MSE、L1、SSIM 的最大 GPU 归约交互绝对值分别为 **5.29396e-22、2.40015e-20、1.77877e-20**，全部在记录的舍入误差参照范围内。这里的“全部”是观察结果；预写零交互要求只针对结构分离的22对，不事后扩大成功门槛。

独立 CPU 路径从保存的联合 RGB patch 重建全图并核验原生参考哈希，重算所有损失与拼接关系。CPU／GPU 联合损失变化量最大差为 **1.42302e-17**，在原有门槛内，无额外 CUDA 渲染。四视角各6对中，单项混合损失和与实际联合混合损失没有正／负方向不一致；这不构成总体无交互结论。

两个矩形重叠案例都在 flowers fresh：父项 **1436＋110** 和 **1387＋2773**。看到聚合零结果后才形成的补充 CPU 分析，明确标为事后：两例观察到的单项 RGB 变化重叠像素数均为0，单项 CPU SSIM 变化重叠通道数均为0，联合图像等于分区拼接，逐像素 RGB 与 CPU SSIM 交互峰值均为0。此事实解释这两个有限案例，不能把观察支持替代结构支持作为未来保证。

软件夹具另覆盖同时删除父项及子项追加顺序、分离区域、仅 SSIM 邻域重叠、逐像素区域重叠。精确有理数的三层混合反例中，原始与两个单项删除图值均为2499/2500，联合删除却为49/50，说明观察到单项无变化不足以保证无联合影响。这是通用删除的数学／软件反例，不是本轮真实三角细分的非加性测量。

## 全局正则项的精确补充

归档源码含 `abs(get_opacity).mean()*lambda_opacity`，不是仅包含图像项。假设 N 个非负有效 opacity 总和 S，均值 mu=S/N，k个不同父项各替换为四个继承相同 opacity 的子项，则

`Delta R_k = 3*lambda*(sum(o_i)-k*mu)/(N+3k)`。

而独立单项变化的和以 N+3 为分母；差为

`eta_R,k = -9*lambda*(k-1)*(sum(o_i)-k*mu)/((N+3k)*(N+3))`。

因此，即使图像支持完全分离，全局平均项也一般不满足单项变化相加。若 opacity 属于[0,1]且 k≤N，还可给出基于选中／未选中总和范围的上界。逆平均三角面积项则不同：理想 midpoint 保持总面积 A 时，该项为 lambda_size*N/A，k次编辑增加3k*lambda_size/A，理想算术下可加；浮点中点的面积扰动不能忽略为形式化等式。

公式、域条件、一般 dS／dN 修正及上界见 `TGS_JOINT_GLOBAL_REG_ADDENDUM_V27.md`。SymPy 1.14.0 验证全部恒等式；附带的非零 opacity 交互数值是有理数 toy，不是真实模型测量。没有确认公开权重的历史超参数，也没有把这些理想恒等式冒充 FP32 训练归约或完整训练目标的提升。
