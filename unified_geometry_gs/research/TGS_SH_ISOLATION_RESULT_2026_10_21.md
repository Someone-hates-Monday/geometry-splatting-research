# TGS SH 中心语义隔离：本轮结果与下一步

2026-10-21。按已授权范围完成数学核验与固定输入 CUDA 诊断；没有优化器、重训练、完整训练或本轮速度测试。总体科研目标仍未完成。

本轮已定位一个具体的软件机制：在保留公开 7000 步模型参数的情况下，仅修正 SH 方向中心的构造表达式，会改变四个所选视图的颜色并降低其 PSNR。不能由此推断修正后重新训练的质量。其余逐步诊断版本在这些输入上的差异远小于这一改动。

## 干预、控制和证据

冻结协议为 `TGS_SH_ISOLATION_PROTOCOL_V12.md`，输入与脚本哈希见 `experiments/tgs_sh_isolation_v12/input_plan.json`、`execution_plan.json`。两场景各保留一个此前已经观察过的视图，另外各用预先固定 SHA256 规则选一个新测试视图；旧视图只用于事后解释。四个视图不是四个独立场景或独立训练重复。

主比较为归档原版 SO `9d974f09...` 与既有 SH-only SO `4fa625a4...`。源文件核验确认 forward/backward 各只有一处替换，构建关键参数与源码提交一致：

```cpp
// legacy
(glm::vec3)(center_triangle.x, center_triangle.y, center_triangle.z)
// corrected
glm::vec3(center_triangle.x, center_triangle.y, center_triangle.z)
```

前向诊断只使用前向路径，不能验证上述 backward 改动的实际效果。C++ 逗号表达式与钉住的 GLM 标量构造器使旧外观中心为 q(p)=(p_z,p_z,p_z)，修正后为三维中心 p。

共完成 36 次前向：5 版本 × 4 视图的 20 次主比较，加上原版/SH-only × 两种负对照 × 4 视图的 16 次对照。没有新编译。四组原始 JPEG 与公开 GT PNG 的解码 RGB 全部逐字节相等，没有配准、缩放、裁剪、曝光或颜色调整。仅为新视图取得的成功 Range payload 合计 7,009,584 字节，低于原定 96 MiB 上限。

四个主比较均满足：RGB 改变；7 通道辅助输出、radii、maxblend、贡献者索引和 tile 数逐位不变。degree0 与预计算常量 RGB 两种负对照中，全部保存前向输出逐位相同。模型、相机输入哈希未变。旧视图的相关原版、piecewise、coarse 输出复现此前 v11 保存结果。

独立审计完成 20 组全部主评分，以整数平方误差复算 PNG 主 MSE、独立 Torch PNG 转换和不同滤波顺序复算完整 SSIM，另核验 9,720 个 SSIM 图块/通道值；所有检查通过。SSIM 定义沿用冻结 v11：11×11 高斯窗、sigma=1.5、零填充 5、RGB 平均。次指标为 clipped float；不混用两种口径。

## 数学结果与限制

`TGS_SH_CENTER_MATH_V12.md` 与 SymPy 1.14 的 `math_results.json` 给出一个精确反例：取 p=(1,0,0)，旧 q=0，相机分别为 (1,0,−1)、(1,0,−2)。新方向同为 (0,0,1)，旧方向不同。对合法 degree1 色场 L(e)=1/2−e_x/4，旧颜色分别为 1/2+sqrt(2)/8 与 1/2+sqrt(5)/20，均在 (0,1) 内。

因此不存在对所有合法旧场与相机均有效的、仅修改方向 SH 系数而与相机无关的普适转换；对此反例，即使允许任意方向函数，也不能同时匹配两个颜色。最佳两样本最大单通道误差为 sqrt(2)/16−sqrt(5)/40≈0.0324866482，中点取得。它不是实际图像 PSNR 下界，不排除常量色场或受限相机集合可转换，也不构成原创性声明。

同时核验了 q 的 Jacobian、共同平移缺陷，以及在明确假定的孤立颜色梯度形式下的链式差异和非零混合偏导差。后者不是完整 CUDA 反向的运行时证明，更不是训练失败的证明。

## 决策与下一步

1. 保留精确窗口/原生 64 位路径作为数值诊断参照，降低继续为它扩大同类计时实验的优先级。已有成本证据与本轮微小的后续质量差异，尚不足以支持独立的质量/效率成果。
2. 将接下来的问题明确为：几何基元变动时，怎样保留或有控制地改变视角相关外观，同时使梯度与实际前向一致。先核对外观锚点、共享外观与密化相关的一手文献；不得把已有 anchor 思路重新命名后当成创新。
3. 可检验候选是显式区分几何中心与外观中心，或对几何重参数化给出外观误差界。需先明确退化情况、与已有方法的区别及固定输入的失败门槛，再做新的小规模实现。本轮尚未实现或证明该候选有效。
4. 在任何完整训练之前，先通过孤立颜色路径的运行时导数核验、原权重外观兼容性检查及明确定义的新方法对照。当前授权仍不包含完整训练。

本轮证明了这几个冻结输入上的软件干预效应，尚未证明公开权重确由该归档提交训练、跨数据集收益、几何质量改善、重训练收益或方法新颖性。它也不能直接解释 GGGS 负结果，因为共享代码路径未建立。当前打开的 `median_depth_note.tex` 与原生产训练源码未改。
