# G-GS / UGGS：完整算法流程设计

> 本文把已做消融收成原则，再定义一条有边界的算法管线。  
> **目标**：网格 Chamfer（overall / s2d）优先，图像 PSNR 不崩。  
> **评测锁**：scan24 / 105 / 122；相对对照的平均 overall ≤ −5e−4、s2d ≤ 0、PSNR Δ ≥ −0.2 dB。

---

## 0. 问题陈述（哲学）

三维高斯同时服务两件事：**看对**（光度）和**形对**（几何）。二者共用同一套原语（位置、尺度、旋转、不透明度），却不共用同一套可信信号。

- **光度**几乎处处有监督（每像素 RGB）。
- **几何**只有在「多视对应可信」时才有监督；其余像素上的几何梯度是噪声，不是信息。

因此本方法的中心命题不是「再加一项损失」，而是：

> **只在几何信号可信的地方改几何；在信号不可信的地方，宁可少约束，也不要假约束。**  
> **表示（训练场）与建面（提取）分离：训练决定深度场，提取决定等值面；二者各自饱和，不可互相冒充。**

混乱试错的根源，是把「缺网格精度」一律当成「缺训练损失」。证据表明：在可信带内稀疏 NCC 已经吃满训练侧收益；再加密监督会伤网格；而截断体素数一类提取旋钮，可以在**同一套高斯**上再挖出数量级更大的 Chamfer 收益。

## 1. 证据复盘（尝试 → 结论）

对照基线均为 G-GS 默认或当时的主配方 `no_dn`。下表只保留方向性结论。

| 阶段 | 尝试 | 相对谁 | 网格 | 图像 | 结论 |
|------|------|--------|------|------|------|
| LOO | 去掉 depth-normal（`no_dn`） | baseline | **平均 overall ≈ −3.8e−3** | 可接受 | **DN 是害项；主训练配方定为 no_dn** |
| LOO | 去掉多视 / 只留 geo | baseline | 崩 | — | NCC 是几何主信号；geo 单独不够 |
| LOO | 只留 NCC（geo=0） | baseline | 弱于 no_dn | — | 极小 geo 有用，不可替代 NCC |
| + | 遮挡 / field-occ / router | baseline 或 no_dn | 未过线 | — | 屏幕/场遮挡项不能替代可信 NCC |
| + | NCC 相关加权、门控 DN | no_dn | 未过线 | — | 在可信带外或旁路重新引入 DN 无效 |
| + | fail-cover（warp 成功但 `ncc≥0.9`） | no_dn | overall **+2.0e−3** | PSNR 持平 | **不可信对应上的几何梯度有害** |
| + | 有序 top-2 近邻平均（MV2） | no_dn | overall **+8.8e−3** | 不稳 | **加密多视 ≠ 更真几何** |
| 诊断 | scan122 d2s（no_dn vs baseline） | — | d2s +2.7e−3 | — | 近带整体偏远为主，远带为辅 |
| 提取 | 冻结 no_dn，扫 TSDF | no_dn 默认提取 | **trunc4：overall −2.0e−2**；v001 亦 PASS | 不变 | **建面未饱和；训练侧先停** |

**合成句**：几何增益来自「单近邻 + 可信 NCC 带 + 极小 geo + 无 DN」的训练场，再经「偏紧的 TSDF 截断」建面。任何把监督扩到低相关、或多视平均的做法，都在跟这条命题作对。

## 2. 三条原则（不可再违反）

**P1 — 可信带封闭**  
主 NCC mask 定义为 warp 有效且 `clamp(1−c²) < 0.9`（即 `c² > 0.1`）。  
- 带内：允许几何梯度（depth / normal → 高斯几何参数）。  
- 带外：禁止新增几何光度项（fail-cover、低相关加权、门控 DN 回流等）。  
- 梯度只进几何，不进球谐颜色（由 warp-NCC 的 CUDA 反向保证）。

**P2 — 稀疏优于稠密**  
每个训练视角只采 **一个** 近邻（在 `nearest_id` 中随机，与 G-GS 一致）。  
第二近邻、多近邻平均，在证据上会把 scan24 等场景的表面拉坏。加密视角之前，必须先证明单近邻的可信带已经用尽——当前没有。

**P3 — 表示 / 建面双阶段**  
| 阶段 | 输入 | 输出 | 允许动的旋钮 | 禁止 |
|------|------|------|--------------|------|
| A. 训练场 | 图像 + 多视 | 高斯 + `median_depth` | λ 仅限已验证集合 | 为修 d2s 盲目加损 |
| B. 建面 | 冻结高斯 | `recon_post.ply` | voxel / trunc / depth_max / clusters | 用训练损失冒充截断 |

scan122 上 no_dn 相对 baseline 的 d2s 超额，在提取扫中被 trunc4 / v001 **直接抹掉并反超**；说明该超额主要是等值面/截断问题，不是「再缺一项 L」。

## 3. 完整算法流程

```
                    ┌─────────────────────────────────────┐
                    │  Stage 0  数据与近邻图               │
                    │  DTU 多视 → 相机；nearest_id 有序表  │
                    └─────────────────┬───────────────────┘
                                      ▼
                    ┌─────────────────────────────────────┐
                    │  Stage A  几何感知高斯训练（表示）    │
                    │  配方锁：no_dn + 单近邻可信 NCC      │
                    └─────────────────┬───────────────────┘
                                      ▼
                    ┌─────────────────────────────────────┐
                    │  Stage B  TSDF 建面（提取）          │
                    │  默认：trunc_voxel_multiplier=4      │
                    │  可选：voxel=0.001（已 PASS，备选）  │
                    └─────────────────┬───────────────────┘
                                      ▼
                    ┌─────────────────────────────────────┐
                    │  Stage C  评测与门禁                 │
                    │  图像 PSNR + DTU Chamfer + d2s 分带  │
                    └─────────────────────────────────────┘
```

### Stage 0 — 数据与近邻

1. 加载 DTU 训练相机与掩码。  
2. 按距离与视线夹角构造每个视角的 `nearest_id`（有序，长度 ≤ `multi_view_num`）。  
3. 近邻图在训练中只读；**不**在损失里对多个近邻做无权重平均（P2）。

### Stage A — 训练场（表示学习）

**冻结配方（主线，称 `G-GS-T` / 现 `no_dn`）**

| 量 | 值 | 理由 |
|----|-----|------|
| `λ_depth_normal` | **0** | LOO：DN 损害网格 |
| `λ_multi_view_ncc` | **0.6** | 几何主信号 |
| `λ_multi_view_geo` | **0.02** | 轻量重投影稳定 |
| `multi_view_ncc_views` | **1** | P2；MV2 已否决 |
| `λ_ncc_fail` | **0** | P1；fail-cover 已否决 |
| `λ_occ` / field-occ / gate-dn / corr-weight | **0 / off** | 未过线，不进主线 |
| `regularization_from_iter` | 7000 | 与 G-GS 一致，先光度后几何 |

**单步计算（reg 开启后）**

1. 渲染：RGB、`median_depth`、渲染法线。  
2. 采样一个近邻相机。  
3. PatchMatch：  
   - 几何一致性 mask `d_mask`（重投影噪声阈值）；  
   - warp-NCC → `c²`，`ncc = clamp(1−c²)`；  
   - **可信 mask** `m = (ncc < 0.9) ∧ valid`；  
   - `L_ncc = mean((ncc · w_reproj)[m])`；  
   - `L_geo = mean((w_reproj · pixel_noise)[d_mask])`。  
4. 总损失：  
   `L = L_rgb + 0.6 L_ncc + 0.02 L_geo`  
   （无 DN、无 fail、无第二近邻。）  
5. 反向：NCC/geo → 深度/法线 → 高斯几何；RGB → 外观与几何（标准 3DGS）。

**训练期不变量**

- 不在 `¬m` 上引入任何几何光度项。  
- 不把 depth-normal 或遮挡项当作「补 NCC 覆盖」的旁路。  
- Soft-stop 仅用于工程中断；不改变配方定义。

### Stage B — 建面（提取）

输入：Stage A 收敛的高斯（冻结）。  
过程：各训练视 `median_depth`（掩码外置 0）→ Open3D `VoxelBlockGrid` TSDF → 最大连通块。

**默认提取（已由冻结高斯扫过线，称 `Extract-T4`）**

| 量 | 值 | 证据 |
|----|-----|------|
| `voxel_size` | 0.002 | 默认；v001 亦 PASS 但更重 |
| `depth_scale` | 1.0 | 深度已是度量单位 |
| `depth_max` | 8.0 | dmax 6/10 近似无影响 |
| `trunc_voxel_multiplier` | **4.0** | vs 默认 8：平均 overall **−2.0e−2** |
| `num_cluster` | 1 | c2 无收益 |

**提取不变量**

- 改提取不得改高斯；比较提取时 PSNR 必须相同。  
- 新提取默认要相对 `Extract-T4` 过门禁，不得只看单场景。  
- 粗体素（0.004）与大截断（12）已证伪，不再回退。

### Stage C — 评测与门禁

对每个扫描：

1. **图像**：训练视角子集 PSNR / SSIM / LPIPS（提取对比可跳过）。  
2. **网格**：官方 DTU `mean_d2s` / `mean_s2d` / `overall`。  
3. **分带（可选，诊断）**：`diagnose_d2s` 的近/中/远对均值贡献——用于判断是表面偏置还是浮片，**不**单独作为过线指标。

**采纳规则（硬）**

- 相对指定对照，三场景平均：overall ≤ −5e−4 且 s2d ≤ 0 且 PSNR Δ ≥ −0.2。  
- 单场景变好、平均不过线 → **不采纳**。  
- 训练改动与提取改动必须分开报；禁止「改了损失又改了截断」绑成一次实验。

## 4. 模块边界（实现哲学）

按「深模块」划分，避免再把旋钮摊在 `train.py` 表面：

| 模块 | 接口（调用方只需知道） | 内部 |
|------|------------------------|------|
| **TrustedNCC** | `(render_pkg, ref, nearest) → L_ncc, L_geo` | warp、mask、权重；**不**暴露 fail-cover |
| **TrainRecipe** | 命名配方 `no_dn` | λ 字典；新 λ 默认 0 |
| **ExtractRecipe** | 命名配方 `trunc4` | voxel/trunc/… |
| **Gate** | `(baseline, candidate) → PASS/FAIL` | 三场景均值与分项 |

已否决的机制可以留在代码里，但**不得**进入 `TrainRecipe` 默认，也不得出现在主线脚本的默认参数中。

## 5. 主线定义（当前冻结）

```
Pipeline* = Train(no_dn)  →  Extract(trunc4)  →  Eval(DTU24/105/122)
```

- **Train(no_dn)**：§3 Stage A 表。  
- **Extract(trunc4)**：`trunc_voxel_multiplier=4`，其余默认。  
- 代码落点：`train.py` 默认损失组合 + `mesh_extract.py` 默认 trunc=4；脚本 `run_ggs_ablation.sh`（no_dn）与提取扫中的 `ex_trunc4`。

备选提取（已 PASS，非默认）：`voxel_size=0.001`（`ex_v001`）——若需进一步压 s2d，只允许在 Stage B 做 **单因子或已登记的双因子** 对比，不重开训练。

## 6. 若仍要研究：唯一合法的下一问

在 Pipeline* 已定义的前提下，只允许按下面顺序提问（每问一次实验，先假设后动手）：

1. **B 是否未饱和？**  
   假设：`v001+trunc4` 相对 `trunc4` 仍能过门禁。  
   动作：冻结高斯，只提一次组合提取。  
   否证：不过线 → Stage B 关闭；进入 2。

2. **A 的深度场是否在局部系统性偏？**  
   假设：scan122 上 no_dn 与 baseline 的 `median_depth` 差集中在轮廓/掠射，而非物体内部。  
   动作：只诊断，不训练。  
   否证：差在内部均匀 → 表示上限，停；是局部 → 才允许 3。

3. **可信带是否过宽？**  
   假设：把 `ncc < 0.9` 收到更严（如 `0.5`）会减少错误几何拉力。  
   动作：单近邻、无 DN、无 fail；三场景门禁。  
   这是对 P1 的**收紧**，不是扩张。扩张类想法（fail-cover、MV2、DN）列在否决表，不再开题。

4. **换建面表示？**  
   仅当 1–3 全否证：讨论非 `median_depth` TSDF 的建面（仍不是 2DGS/TGS 迁移，除非 G-GS 管线显式结案）。

## 7. 否决清单（禁止再开）

| 想法 | 否决原因 |
|------|----------|
| 恢复 λ_dn > 0 | LOO 负收益 |
| fail-cover / 低相关几何项 | P1；overall +2e−3 |
| multi_view_ncc_views ≥ 2 | P2；overall +8.8e−3 |
| NCC 门控 DN、相关加权 | 未过线；旁路破坏 no_dn |
| 屏幕 occ / field-occ 作主增益 | 未过线；与可信 NCC 不同构 |
| 未冻结高斯时同时改损失与 trunc | 混淆 Stage A/B |
| 先堆实验再找故事 | 违反本文流程：先原则与假设，后单因子 |

## 8. 一句话

**用稀疏、高相关的多视几何约束塑造深度场；用偏紧的 TSDF 截断把它变成网格；不在不可信像素上假装有几何监督。**

Pipeline* = `no_dn` 训练 + `trunc4` 提取。一切后续工作必须先归入 §6 的某一问，并接受 §3 Stage C 门禁；否则不做。
